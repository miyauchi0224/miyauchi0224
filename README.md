### 

センサデータなど、現場で集まる**地理空間・時系列データ**を解析し、業務で使えるツールやウェブシステムにする仕事をしています。

#### 使っている技術
- **データ解析・機械学習**：Python（pandas、NumPy、scikit-learn、TensorFlow／Keras）
- **ウェブ開発**：FastAPI、Django REST Framework、React／Next.js、TypeScript
- **データベース・クラウド**：PostgreSQL（PostGIS）、Azure、Docker
- **モバイル**：Swift（SwiftUI）、Android

#### 主なリポジトリ
| リポジトリ | 内容 |
|---|---|
| [HRM](https://github.com/miyauchi0224/HRM) | 人事管理システム（勤怠、給与明細、目標管理、経費申請、電子稟議など）。Next.js／TypeScript と Django REST Framework、JWT 認証、Docker Compose。領収書の OCR や Claude と連携したエージェントなど、AI 支援機能つき。設計書あり |
| [gps_logger](https://github.com/miyauchi0224/gps_logger) | GPS の位置を記録し、CSV 出力や地図（国土地理院地図）表示をするモバイルアプリ。バックグラウンド記録、Wi-Fi 測位への自動切替 |

公開しているのは、個人で開発した学習用のアプリです。実在の会社・個人のデータは使っていません。
